# 测速与地区检测 — 2026-11-06

本次在既有 HTTPS 响应延迟口径上继续优化，不再改变读数定义。目标是减少批量排队与重复会话启动，并让地区检测可见、可取消、不影响正在使用的节点。

## 实现

- 原生测速将 TCP/UDP 节点交错分窗；全局并发常规 3、快速 6、重试 4；UDP 并发常规 2、快速/重试 4。同入口仍串行，窗口最多 24 个监听器。
- 启动节流使用单调时钟，保持原有 100 ms 间隔。采样次数、成功多数门槛、TLS 校验、连接复用与响应中位数未改。兼容后端保持原实现。
- 地区检测读取与连接/节点页相同的 Neo 编译配置。单独监听器访问 HTTPS 查询服务，检测实际出口国家/地区；不切换主 VPN 节点。
- 地区检测按身份去重、最多 24 个监听器/窗、2 个请求并发，同入口串行；单节点查询总预算 8 秒，涵盖建连、TLS、响应头与正文。主查询 ipwho.is 最多使用前半预算，失败/超时时再尝试 Country.is，等待前一请求清理后才开始备用查询；备用结果同样只保留国家/地区。两个提供方不各自消耗完整预算，不降低 TLS 验证。
- 立即显示准备/等待/检测进度；提供停止按钮，离开页面或网络/配置变化时取消。取消会断开 HTTP 请求，等待子任务和探测会话清理，再允许下一次检测。
- 地区结果保存在 node_regions_v2.json，仅包含配置身份 SHA-256、国家/地区标签和时间。旧版仅按节点名的缓存不迁移，避免订阅更新或同名节点串记录。缓存有效期 7 天，最多 2048 条；用原子提交，在完成、停止及离开页面时持久化。失败不覆盖原记录。

当前验收构建基于 neo-mobile-speed-response 隔离目录，排除主工作区尚未验收的规则资源 OTA 变动。仅安装 com.xiaosaik.neo.routingtest 到 OnePlus PLK110；不操作 OPPO、原版 Neo 或游戏，不发布。

单元测试 381 项 / 41 套件通过；隔离构建工具测试 50 项通过，主工程工具测试 51 项通过。Android 真机测试最终 18 项通过，包含新增地区 HTTPS 成功、正文取消、TLS/正文超时与备用查询顺序，以及既有测速、DNS 和更新生命周期回归。

实际出口与测速结果、安装 SHA-256、主连接不变、缓存落盘及资源清理检查以本轮 evidence/routing-20261106-speed-worker/region-*.json 和最终验收摘要为准。结果仅代表本次设备、网络与节点；地区由查询服务数据库返回，不能作为节点机房物理位置保证。
