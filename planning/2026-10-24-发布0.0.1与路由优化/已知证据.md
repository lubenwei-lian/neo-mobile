## 路由 / DNS 优化
- 【事实】优化器（SubGuard.optimize，接入 SubscriptionFetcher.prepare 路径）输出：dns.strategy=prefer_ipv4；fakeip 仅 inet4_range（198.18.0.0/15）；DNS 规则 A→fakeip（国外域名由节点解析）、AAAA/HTTPS/SVCB→带 detour 远端 DNS；出站 domain_strategy 全部移除。
- 【事实】内核兼容性二分实测（真机 TUN 是否建立）：
  · 仅 route.rule_set 改本地 binary 规则集 → 连接失败（内核拒绝）；
  · 仅 dns.strategy=prefer_ipv4 → 成功；仅 fakeip 去 inet6_range → 成功；仅去 domain_strategy → 成功；
  · 组合 C+D+E+DNS 规则（无本地规则集） → 成功。
  → 结论：本地 binary 规则集不兼容，最终采用 DNS 优化子集；国内分流仍用订阅的远程 geosite-cn/geoip-cn。
- 【事实】最终生效配置（设备 files/configs/1.json）：strategy=prefer_ipv4、fakeip 无 inet6_range、route.rule_set=remote:geoip-cn/geosite-cn、domain_strategy 数量 0；真机连接 tun0 建立（172.19.0.0/30）。
