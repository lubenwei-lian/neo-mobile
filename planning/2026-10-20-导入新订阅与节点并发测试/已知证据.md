## 三、导入失败的根因（三层，逐层实证）
1. **远程导入直接失败**：
   `decode config: dns: legacy DNS fakeip options are deprecated in sing-box 1.12.0 and removed in sing-box 1.14.0`
2. **第一轮迁移后**（只改 fakeip server）→ 新错误：
   `dns.servers[1]: legacy DNS server formats are deprecated...`（其余 server 仍用 `address` 写法）
3. **第二轮迁移**（全部 server 改 `type`）→ **通过校验**，弹出导入确认框
