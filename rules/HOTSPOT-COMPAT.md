# 热点与 VPN 共存验证

本次仅验证现有版本的兼容性，没有修改 Neo 转发代码、分流规则或 Root 转发规则。测试时间以证据中的 ISO 时间为准。

## 环境

- 热点宿主机：OnePlus PLK110，Android 16（SDK 36），使用蜂窝数据。
- 热点客户端：Redmi 24069RA21C，Android 14（SDK 34），关闭移动数据，确认实际接入一加热点，防止蜂窝回落掩盖故障。
- Neo：分流测试包 0.0.4 / 13，国旗修复候选。仅操作一加与红米；没有操作其他手机或游戏。

## 结果

| 场景 | 红米 HTTPS | 红米 UDP DNS | 一加 HTTPS |
| --- | --- | --- | --- |
| Neo 已连接，再开启热点并连接红米 | 通过 | 通过 | 通过 |
| 保留热点，断开 Neo | 通过 | 通过 | 通过 |
| 保留热点，重新连接 Neo | 通过 | 通过 | 通过 |

第一轮连续请求 42 次，全部成功，连接复用 41 次。第一轮标准输出存在缓冲，接收时间不能用于判定请求所属阶段，因此另做带实时阶段记录的复测。

第二轮持续 70340 毫秒，36 次请求全部成功，连接复用 35 次。各阶段实际收到的请求数为：vpn-on-initial 3；vpn-disconnecting 3；vpn-off 3；vpn-reconnecting 4；vpn-on-reconnected 23。两轮合计 78 次连续请求，0 次失败；本轮没有观察到 VPN 断开、重连导致红米断网或连接重建。

热点上游观察到蜂窝接口，未观察到以 TUN 为热点上游；本次不构成热点设备共享 Neo 代理出口的实现或验收。

## 最终状态

按用户要求保留一加热点与 Neo 连接，红米继续接入热点且移动数据保持关闭，方便继续使用验证。Neo 首页显示网络可用，原选中节点保持一致，无探测进程或临时探测配置残留。未更改热点名称或密码。

## 范围与限制

- UDP 测试仅覆盖向热点网关发送 DNS 请求并收到有效响应，不能据此保证所有游戏 UDP 会话。
- 尚未覆盖长时间锁屏、IPv6 端到端、大流量、其他品牌或系统组合。
- 两台设备均有 Root；Root 用于读取诊断和让红米连接已有热点，未注入任何热点代理共享或防火墙转发规则。非 Root 设备未单独进行这轮实测。
- HTTPS 检测使用国内网页与连接检测服务，结果仅对应当时的设备和网络。
