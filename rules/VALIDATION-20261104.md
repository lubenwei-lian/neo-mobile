## 当前分流约定

用户覆盖 → 私网 → 已验证应用/游戏策略 → 明确海外域名 → 国内域名 → 国内 IP → 未知公网代理。
全局和直连模式保持各自的显式含义。机场只提供节点及连接依赖，不能覆盖 Neo 的路由/DNS。

PUBG 已验证策略限定 `com.tencent.ig`：UDP 直连，TCP 和剩余流量代理，DNS 代理。
其他游戏不会继承此 UDP 例外。需要全代理的应用可以使用 `global-proxy`；普通分流使用 `domestic-split`。
IP 地区、可建立 TCP 或收到 UDP 字节均不足以单独证明游戏策略正确，必须结合游戏画面验收。

## 规则更新恢复

资源采用不可变 SRS 对象与 current/candidate/previous 指针。下载和暂存不改变当前对局资源；新连接才校验和激活。
候选验证失败保留旧资源；未确认启动、原生启动失败重试、损坏状态恢复以及并发下载继承重基均有 JVM 回归。
真机只专门注入了候选原生验证失败，没有把它冒充为完整 OTA 或原生运行中故障验收。
策略和规则的内置来源随 APK 更新刷新，已确认的下载版本保留。
